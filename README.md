# core-cs

A personal repository for practicing and documenting **Data Structures, Algorithms, and Core Computer Science** concepts.

## Repository Structure

```
core-cs/
├── DSA/                        # Data Structures & Algorithms
│   ├── Arrays/
│   ├── Linked Lists/
│   ├── Trees/
│   ├── Graphs/
│   ├── Sorting/
│   ├── Searching/
│   ├── Dynamic Programming/
│   └── ...
├── Computer Network/           # CN concepts, protocols, socket programming
├── OS/                         # Operating Systems concepts, process & memory management
├── OOP/                        # Object-Oriented Programming in C++
├── Design Pattern/             # Gang of Four & other design patterns
├── DBMS/                       # Database Management Systems, SQL, normalization
├── SP/                         # Structured Programming
└── Hardware/
    ├── DLD/                    # Digital Logic Design
    ├── Microprocessor & Peripherals/ 
    └── Robotics & Arduino/
```

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/Rahatut/core-cs.git
   cd core-cs
   ```

2. Start coding or note-taking in the relevant folder.
